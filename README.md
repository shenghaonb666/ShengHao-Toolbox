## ✨ 核心功能

### 调度模块（米家/蓝厂/欧加）
- 🎯 开机自动识别设备型号 + 芯片平台
- ⚡ 根据机型精准匹配调优参数
- 🎮 检测到游戏自动切性能模式
- 🌡️ 温控智能保护，过热自动降频
- 🎨 粉色 WebUI 控制面板

### 分区工具箱
- 📦 一键提取 boot / init_boot / vendor_boot / recovery / dtbo / vbmeta
- 🛠️ 一键刷入上述分区（支持 A/B 槽位）
- 🔍 自动识别分区目录，安全防砖
- 💾 全分区备份 / 还原

## 📥 下载安装

**调度模块（zip）：**
1. 从对应文件夹下载 .zip 模块包
2. 面具 App → 模块 → 从本地安装
3. 刷入后重启设备
4. 打开 WebUI 查看识别结果

**Shell 脚本（.sh）：**
1. 下载脚本，放到 /sdcard/
2. 终端执行 `su` 后 `sh 脚本名.sh`
