## ✨ 核心功能

- 自动识别机型 + 芯片平台
- 动态游戏加速（330+ 游戏自动识别）
- 温控智能保护，过热自动降频
- 粉色可爱 WebUI 面板
- 一键切换性能 / 均衡 / 省电 / 游戏模式

## 📥 安装

1. 下载 `勝豪欧真加调度模块.zip`
2. 面具 App → 模块 → 从本地安装
3. 刷入后重启
4. 打开 WebUI 查看识别结果
