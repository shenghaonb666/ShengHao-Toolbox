# 🔧 勝豪分区工具箱

安卓分区备份 / 提取 / 刷入 工具

作者：勝豪 · Q群：1022873156

---

## ✨ 功能

- **提取**：boot / init_boot / vendor_boot / recovery / dtbo / vbmeta
- **刷入**：支持上述分区，自动识别 A/B 槽位
- **自定义**：可手动选择任意分区提取或刷入
- **安全保护**：镜像大于分区时拒绝写入，刷前必须确认
- **自动识别**：自动探测 `/dev/block/by-name` 等分区目录
