## 📱 覆盖机型（160+）

- 小米数字系列：小米2 到 小米17 全覆盖
- 小米 MIX / Note / CC / Civi / Max / Play
- 小米平板 5/6/7 全系

- POCO F / X / M / C 全系

## ✨ 核心功能

- 自动识别机型 + 芯片平台
- 动态游戏加速（330+ 游戏自动识别）
- 温控智能保护，过热自动降频
- 粉色可爱 WebUI 面板
- 一键切换性能 / 均衡 / 省电 / 游戏模式

---

## 📥 安装

1. 下载 `勝豪米家调度模块.zip`
2. 面具 App → 模块 → 从本地安装
3. 刷入后重启
4. 打开 WebUI 查看识别结果
